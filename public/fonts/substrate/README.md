# Substrate fonts

Self-hosted Latin WOFF2 subsets from official Fontsource npm packages:

- Inter variable normal: @fontsource-variable/inter@5.3.0
- Lora 400 italic: @fontsource/lora@5.3.0
- Fraunces variable normal: @fontsource-variable/fraunces@5.3.0
- IBM Plex Mono 400 normal: @fontsource/ibm-plex-mono@5.3.0

These are open-source substitutes named by the supplied style references.
Matching licenses are included beside the font files.
